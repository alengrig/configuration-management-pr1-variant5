## Общее описание

Проект представляет собой эмулятор командной оболочки
UNIX-подобной операционной системы.

Приложение реализуется на Python в форме консольного
интерфейса.

На первом этапе реализован минимальный REPL.

## Реализованная функциональность

На этапе 1 реализованы:

- интерактивный консольный интерфейс;
- приглашение на основе имени пользователя и имени компьютера;
- простой разбор команды и аргументов по пробелам;
- команда-заглушка `ls`;
- команда-заглушка `cd`;
- команда `exit`;
- сообщение об ошибке для неизвестной команды.

## Примеры использования

Пример команды `ls`:

```text
username@hostname:~$ ls docs
ls: ['docs']
```

Пример команды `cd`:

```text
username@hostname:~$ cd docs
cd: ['docs']
```

Пример неизвестной команды:

```text
username@hostname:~$ hello
Error: unknown command: hello
```

Для завершения работы:

```text
username@hostname:~$ exit
```

## Этапы разработки

### Этап 1. REPL

Создан минимальный прототип командной оболочки.
Реализованы REPL, простой парсер, заглушки `ls` и `cd`,
команда `exit` и базовая обработка ошибок.
## Этап 2. Конфигурация

На этапе 2 добавлена поддержка параметров командной строки
и стартовых скриптов.

### Параметры командной строки

Поддерживаются следующие параметры:

- `--vfs PATH` — путь к физическому расположению VFS;
- `--script PATH` — путь к стартовому скрипту.

Пример запуска с путем к VFS:

~~~bash
./run.sh --vfs examples/vfs/basic
~~~

Пример запуска со стартовым скриптом:

~~~bash
./run.sh --script examples/startup/stage2_ok.txt
~~~

Оба параметра можно использовать одновременно:

~~~bash
./run.sh \
    --vfs examples/vfs/basic \
    --script examples/startup/stage2_ok.txt
~~~

При запуске приложение выводит текущую конфигурацию.

На этапе 2 параметр `--vfs` только считывается и выводится.
Загрузка виртуальной файловой системы будет реализована
на этапе 3.

### Стартовый скрипт

Стартовый скрипт содержит команды эмулятора,
которые выполняются последовательно.

Во время выполнения на экран выводятся как команды,
так и результаты их выполнения.

При возникновении первой ошибки выполнение стартового
скрипта немедленно прекращается.

Пример корректного стартового скрипта:

~~~text
ls
cd docs
ls test.txt
exit
~~~

Пример скрипта с ошибкой:

~~~text
ls
hello
cd this-command-must-not-run
~~~

После ошибки команды `hello` следующая команда уже
не выполняется.

### Скрипты проверки этапа 2

Для проверки параметров командной строки созданы
скрипты macOS:

~~~text
scripts/stage2/test_vfs.sh
scripts/stage2/test_script.sh
scripts/stage2/test_all.sh
~~~

Запуск:

~~~bash
./scripts/stage2/test_vfs.sh
./scripts/stage2/test_script.sh
./scripts/stage2/test_all.sh
~~~

На этапе 2 реализованы параметры `--vfs` и `--script`,
отладочный вывод конфигурации, выполнение стартового
скрипта и остановка на первой ошибке.
